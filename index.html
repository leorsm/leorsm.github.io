Pac-Man

A neon-styled Pac-Man in Python and pygame, with procedurally generated mazes and ghosts that chase you with pathfinding. A two-person 42 project, shipped as a standalone Linux build.

  • Designed the ghost AI: BFS pathfinding with a tunable chase probability, ghosts that wake up progressively as pacgums are eaten, and a fleeing behavior when they become edible.
  • Built the core game rules: smooth movement between cells, collision detection on the interpolated positions (so hits match what's on screen), timers, lives, and difficulty that scales per level.
  • Made it robust: a validated JSON config with safe defaults, graceful handling of missing audio and interruptions instead of crashes, and a codebase that passes flake8 and mypy --strict.
  • Packaged it with PyInstaller and a Makefile build, and deployed it on itch.io with butler.

Inception

A three-container web infrastructure (NGINX, WordPress, MariaDB) built from scratch with Docker Compose, fully reproducible with a single make.

  • Wrote a Dockerfile for each service from a bare Debian image (no prebuilt images). NGINX is the only entry point, and it serves HTTPS on port 443 with TLS 1.2/1.3 only.
  • Automated the whole setup: on an empty database, init scripts install WordPress with WP-CLI and create two users, and they are safe to re-run at every restart.
  • Kept credentials out of the code and out of Git, using Docker secrets for passwords and an .env file for the rest.
  • Set up an isolated Docker network, two named volumes that persist data across crashes and rebuilds, and automatic restart on failure.
